# Projeto Nexa&DIO - Natural ou Fake Natty? Como Vencer na Era das IAs Generativas

## 📋 Descrição
Este projeto foi desenvolvido durante o bootcamp disponibilizado pela DIO em dezembro de 2025. A experiência proporcionou uma interação enriquecedora com os conceitos fundamentais da criação de IA, incluindo linguagem neural, visão computacional, algoritmos, robótica e lógica de programação. Durante o desafio, testamos na prática diversas ferramentas de IA generativa, como ChatGPT, Leonardo IA e outras, explorando seu potencial para criar conteúdos realistas e inovadores.

## 🛠️ Tecnologias Utilizadas
- Chat GPT
- Leonardo AI
- HeyGen

## 🎨 Processo de Criação
*A ideia inicíal foi criar uma propaganda para uma empresa de tecidos, no qual o metro da seda vai sair mais barato a cada 5 metros, o chat GPT ficou responsável por criar o texto de publicação (marketing), aproveitando a ideia da promoção, resolvi também criar uma logo no Leonardo AI, e para finalizar, fiz um vídeo de publicação da propagando pelo HeyGen.*

## 💭 Reflexão
A IA é uma excelente aliada no ambiente de criação, ou em qualquer outro contexto profissional. Atualmente, dispomos de diversas ferramentas de IA que são extremamente eficientes e elaboradas, capazes de potencializar nossa criatividade e produtividade de maneiras inovadoras. Este projeto evidenciou como essas tecnologias podem ser utilizadas para superar desafios criativos e técnicos, abrindo novas possibilidades para desenvolvedores e criadores de conteúdo.
