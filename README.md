# 📘 IA Generativa: Criatividade Artificial ou Inteligência Humana Amplificada?

## 📒 Descrição
Este projeto consiste na criação de um eBook educativo sobre Inteligência Artificial Generativa, explorando seus conceitos, funcionamento, aplicações reais e reflexões éticas. Inspirado no desafio **Natty or Not** da DIO, o material questiona até que ponto a criatividade gerada por IA é realmente “natural” ou apenas uma amplificação da inteligência humana.

## 🤖 Tecnologias Utilizadas
- ChatGPT (IA Generativa de Texto)
- GitHub (Versionamento e Portfólio)
- Markdown
- Ferramentas de edição de texto (para conversão em PDF)

## 🧐 Processo de Criação
O conteúdo foi desenvolvido a partir de estudos sobre IA Generativa, combinando conhecimento técnico, reflexão crítica e criatividade humana. A IA foi utilizada como ferramenta de apoio na estruturação e refinamento do texto, mantendo o direcionamento, curadoria e visão estratégica humanas.

## 🚀 Resultados
- Criação de um eBook completo sobre IA Generativa
- Conteúdo pronto para publicação em PDF ou GitHub
- Material aplicável para portfólio profissional e educacional

## 💭 Reflexão
Criar algo “natty” com IA exige equilíbrio. A tecnologia acelera e amplia possibilidades, mas o diferencial continua sendo humano: pensamento crítico, ética e intenção. A IA não substitui o criador — ela potencializa.
