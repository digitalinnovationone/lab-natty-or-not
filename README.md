Título do Projeto Extremamente Aesthetic ;)

Por: Weslen Araujo dos Santos

📒 Descrição

Este projeto foi criado como parte do Lab Natty or Not da DIO com o objetivo de explorar até que ponto IAs Generativas conseguem produzir conteúdos indistinguíveis de textos escritos exclusivamente por humanos. Mais do que gerar texto, a proposta foi trabalhar curadoria, refinamento e intenção, usando a IA como apoio criativo — e não como atalho.

O foco foi criar um material que pudesse tranquilamente fazer parte de um portfólio profissional, sem soar artificial, genérico ou “robotizado”.

🤖 Tecnologias Utilizadas

ChatGPT (IA Generativa de Texto)

Git e GitHub

Markdown

Editor de texto (VS Code)

Revisão humana manual em todas as etapas

🧐 Processo de Criação

O processo foi intencionalmente dividido em etapas, simulando a forma como uma pessoa realmente cria conteúdo no dia a dia:

Definição do objetivo antes da IA
Antes de qualquer prompt, foi definido:

Público-alvo (recrutadores e estudantes de tecnologia)

Tom (humano, profissional, sem exageros técnicos)

Objetivo final (README que pareça escrito por uma pessoa real)

Geração de rascunhos com IA
A IA foi usada para gerar versões iniciais, nunca como versão final. Cada resposta passou por leitura crítica, cortes e reescrita manual.

Refino humano
Ajustes de ritmo de frase, remoção de repetições, inclusão de pequenas opiniões e escolhas subjetivas — elementos difíceis de simular sem intervenção humana.

Iteração consciente
Várias versões foram descartadas até chegar em um texto que “soasse certo” ao ler em voz alta.

🧠 Exemplos Reais de Prompts Utilizados

Abaixo estão prompts reais, do tipo que um ser humano realmente escreve — simples, diretos e ajustados ao longo do processo.

🔹 Prompt 1 — Geração inicial da descrição
Escreva uma descrição de projeto para um README da DIO.
Tema: uso de IAs Generativas.
Tom: profissional, mas humano.
Evite parecer texto de marketing.


📌 Resultado: Texto correto, porém genérico.
📌 Ação humana: Mantive a estrutura, mas reescrevi frases para incluir intenção pessoal.

🔹 Prompt 2 — Tornar o texto mais humano
Reescreva o texto abaixo deixando mais natural,
como se fosse escrito por alguém explicando o próprio projeto.
Não use palavras muito técnicas.


📌 Resultado: Melhor fluidez.
📌 Ação humana: Cortei exageros e acrescentei pequenas decisões pessoais (“a ideia foi”, “o foco foi”).

🔹 Prompt 3 — Processo de criação
Explique um processo de criação usando IA,
mas deixando claro que houve revisão humana.
Escreva em forma de etapas simples.


📌 Resultado: Estrutura clara em tópicos.
📌 Ação humana: Ajustei a ordem das etapas para refletir o que realmente aconteceu.

🔹 Prompt 4 — Reflexão final (Natty or Not)
Escreva uma reflexão curta sobre o desafio
de criar algo que pareça humano usando IA.
Tom: honesto e equilibrado.


📌 Resultado: Texto reflexivo, porém neutro demais.
📌 Ação humana: Acrescentei opinião própria e conclusão pessoal.

🔹 Prompt 5 — Ajuste de tom
Deixe o texto um pouco mais informal,
mas sem perder profissionalismo.


📌 Resultado: Linguagem mais próxima do dia a dia.
📌 Ação humana: Pequenos ajustes finais de vocabulário.

🚀 Resultados

README com linguagem natural e fluida

Texto que não soa genérico nem artificial

Demonstração clara do uso consciente de IA

Projeto pronto para portfólio e entrevistas técnicas

💭 Reflexão

O maior aprendizado deste desafio foi entender que usar IA bem não é apertar um botão, mas saber o que pedir, quando ajustar e o que descartar.
A IA acelera, mas o critério, o contexto e o senso humano continuam sendo insubstituíveis.

📌 Consideração Final

Este projeto não busca esconder o uso de IA, mas provar que a diferença está em quem conduz o processo — e não apenas na ferramenta.
